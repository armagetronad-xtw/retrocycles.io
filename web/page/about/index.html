What this is

Retrocycles.io runs Armagetron Advanced, the open-source lightcycle game, in a web browser. The game's original client is compiled to WebAssembly, so it plays the same as the desktop version and connects to the same servers. No installation or account is needed.

Retrocycles is the name Armagetron Advanced uses on Steam. The servers and the community use the name Armagetron.

Made by the Armagetron Advanced project

Armagetron Advanced was started by Manuel Moos in 2000 and has been developed since by the project's developers, contributors and translators. Retrocycles.io provides the browser port and an optional platform.

Project website: armagetronad.org. The source code is on GitLab, and the community has a wiki.

Licence and platform

Armagetron Advanced is free software, released under the GNU General Public License, version 2 or (at your option) any later version. The same licence covers the browser client served here, this website and the changes that make the game run in a browser.

Retrocycles.io also runs an optional platform that provides sign-in (guest or account), Quick Play, progress and levels, and moderation in the official rooms. The platform is a separate service, not part of the game, and is not needed to play or to host a server. Community servers work as before. The game communicates with the platform over an open, published protocol that anyone can implement.
